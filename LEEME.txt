PEÑA LOS SECATIS · cuentas (versión para Synology) (Web Station + PHP)

QUÉ HACE
Guarda las cuentas en el NAS. Cualquiera con el enlace las ve en solo lectura
(se actualizan solas cada 5 segundos). Solo quien conoce la contraseña puede
editar, con el botón "Entrar como editor".

ANTES DE SUBIR
1. Abre api.php con un editor de texto y cambia la línea
   $PASSWORD = 'cambia-esta-clave';
   por tu contraseña.

INSTALACIÓN
1. Centro de paquetes: instala Web Station y un paquete PHP (7.4 u 8.x).
2. En la carpeta compartida "web" crea la carpeta "cuentas-pena" y sube dentro
   index.html, api.php y la carpeta "datos".
3. Web Station: crea un servicio web de tipo "Sitio web de lenguaje de scripts"
   (PHP), con raíz de documentos web/cuentas-pena.
4. Web Station: crea un portal web que use ese servicio, con un puerto
   (por ejemplo HTTP 8080).
5. File Station: clic derecho en las carpetas "datos" y "fotos" > Propiedades >
   Permisos, y da lectura y escritura al usuario "http" (en las dos).
6. Abre http://IP-DEL-NAS:8080
   (los nombres de menús pueden variar según tu versión de DSM)

USO
- Socios: abren el enlace y ven las cuentas.
- Tesorero: pulsa "Entrar como editor", escribe la contraseña y edita.
- Para traer los datos de la versión de Claude: allí, Ajustes > copia el texto;
  aquí, Ajustes > pégalo > "Cargar texto pegado".

FOTOS
- La pestaña Fotos agrupa las fotos por partido (por fecha) y cada partido tiene
  "Subir foto". Las fotos se reducen en el móvil antes de subirlas.
- Por defecto cualquiera con el enlace puede subir fotos. Si prefieres que solo suba
  el editor, abre api.php y cambia  $FOTOS_ABIERTAS = true;  por  false.
- Borrar una foto: solo el editor ("Entrar como editor"), desde la foto ampliada
  (icono de papelera, y después "¿Seguro?"). Si falla, la app muestra el motivo; lo
  habitual es que el usuario "http" no tenga permiso de escritura en la carpeta fotos.
- Si una subida falla por tamaño, sube upload_max_filesize y post_max_size en el
  perfil PHP de Web Station (por defecto suelen ser 2 MB).

SEGURIDAD
- Dentro de tu red local basta con HTTP. Si lo abres a Internet, hazlo con HTTPS
  (Panel de control > Portal de inicio de sesión > Avanzado > Proxy inverso),
  porque la contraseña viaja al editar.
- Las cuentas son visibles para cualquiera que tenga el enlace.

COPIA DE SEGURIDAD
Copia de vez en cuando el archivo datos/cuentas.json.

DATOS INCLUIDOS
La carpeta datos ya trae cuentas.json con el estado actual de tus cuentas en la versión de Claude (socios, partidos, resultados, goleadores y convocatorias), así que no hace falta importar nada. Si ya tenías datos en el NAS, NO sobrescribas la carpeta datos.
